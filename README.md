# Привратник для Telegram-группы

![cover_image](./docs/cover_image.jpg)

Бот для открытых групп: соседских чатов, клубов, сообществ по интересам. Новичок может вступить
сразу, но писать сможет только после того, как ответит в личке с ботом на вопрос, который знают
только «свои»: номер автобуса у дома, почтовый индекс, номер школы во дворе. Спам-боты и случайные
люди отсеиваются, а настоящим участникам почти не мешает.

- Вступление без заявок и ожидания: новичок сразу видит переписку.
- До ответа новичок не может писать; всё, что он успел отправить, удаляется.
- Вопрос задаётся в личке, группа не засоряется: после проверки бот удаляет
  приветствие и переписку.
- Несколько вопросов, каждому новичку достаётся случайный. Часть букв в тексте вопроса
  заменяется латинскими двойниками, чтобы сбить ботов.
- Три попытки, потом вечный бан. Кто не ответил за 48 часов, удаляется, но может вступить снова.
- Администраторы получают уведомления с кнопками «Одобрить», «Забанить», «Разбанить».
- Людей, которых добавил администратор, бот не проверяет.
- Поддерживаются группы с темами.

Работает на бесплатном тарифе _Cloudflare Workers_ и базе _D1_, без своего сервера.

**Как установить:** [docs/HOWTO.md](docs/HOWTO.md). Займёт около получаса.

Коротко:

```sh
cp config.example.env config.env         # Аккаунт в Cloudflare и группа, которую защищаем
cp questions.example.json questions.json # Ваши вопросы и ответы
scripts/deploy.sh                        # Установка и токен бота
```
